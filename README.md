# RiskTým - ukázka

Nástroj na FMEA porady: tým rozhodne jednou na poradě a PFMEA, kontrolní plán, seznam opatření, zápis i 8D se vyplní samy.

Ukázková verze. Výrobce nářadí Ozubené kolečko, jeho aku vrtací šroubovák, osoby i všechna rizika jsou vymyšlené.

**Vyzkoušet:** https://simoonka.github.io/risktym-ukazka/

- `index.html` - úvodní stránka
- `fmea.html` - trénink FMEA porady pro nováčky (5 rizik, kontrolní plán, reklamace 8D)
- `porada.html` - nástroj na skutečnou poradu (ukázkový projekt a velká ukázka s 22 riziky)

Běží jen v prohlížeči, bez serveru a databáze. Data zůstávají v prohlížeči nebo v souboru na disku.
